# Дорожная карта и решения

Живой документ: что решили, почему, и что дальше.

## Решения по продукту (согласовано 2026-10-03)

| Тема | Решение |
|---|---|
| Платформы | Linux (ПК) + Android |
| Язык интерфейса | английский (по умолчанию) и русский, переключатель в настройках |
| Источники медиатеки | Android: MediaStore + выбранные папки (без `MANAGE_EXTERNAL_STORAGE`). ПК: выбранные папки + отслеживание изменений |
| Папка загрузок | Android: `Music/ViPlayer`, ПК: `~/Music/ViPlayer` — вне приватного хранилища, переживает переустановку |
| Источники скачивания | YouTube / YT Music, SoundCloud, Spotify (пока только ссылки) |
| Режимы скачивания | раздельно: **по ссылке** и **по названию** |
| Формат | по умолчанию **AAC `.m4a`** без перекодирования; в настройках Opus и MP3 (MP3 только ПК) — см. [DOWNLOADS.md](DOWNLOADS.md) |
| Синхронизация | полная ПК ↔ телефон по LAN, без сервера — см. [SYNC.md](SYNC.md) |
| Офлайн на телефоне | «Понравившееся» + плейлисты с флагом «офлайн»; всё с телефона копируется на ПК |
| Дизайн | чёрный (OLED) + неоновые акценты, скошенные углы, короткие анимации |
| applicationId | `com.viplayer.app` (менять нельзя) |

## Этапы

1. ✅ **Каркас** — проект, git, структура, тема, БД, локализация, скрипты, документация
2. **Медиатека** — папки, сканер, теги, обложки, поиск по медиатеке
3. **Плеер** — очередь, shuffle/repeat, перемотка, мини- и полный плеер, фон, медиаклавиши / MPRIS
4. **Плейлисты и «Понравившееся»**, история
5. **Скачивание по ссылке** — yt-dlp на ПК, Dart на Android
6. **Скачивание по названию** — поиск и выбор результата
7. **LAN-синхронизация** — метаданные, затем файлы и стриминг
8. **Полировка** — анимации, производительность, тесты, релиз

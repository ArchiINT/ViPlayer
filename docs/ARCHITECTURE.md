# Архитектура

## Стек

| Задача | Решение |
|---|---|
| UI | Flutter (Material 3, своя тёмная тема) |
| Состояние | Riverpod 3 (без кодогенерации) |
| Навигация | go_router, `StatefulShellRoute` — у каждой вкладки свой стек и скролл |
| База данных | Drift (SQLite) |
| Локализация | `flutter gen-l10n`, ARB-файлы в `lib/l10n/` |
| Воспроизведение *(этап 3)* | media_kit (libmpv) + audio_service (фон, уведомление, MPRIS) |
| Скачивание *(этапы 5–6)* | yt-dlp + ffmpeg на ПК, Dart-реализация на Android |

## Структура

```
lib/
  main.dart                 запуск: загрузка настроек, ProviderScope
  app.dart                  MaterialApp: тема, язык, роутер
  core/                     инфраструктура, не знает о конкретных экранах
    database/               Drift: tables.dart (схема), app_database.dart
    platform/               пути, особенности платформ
    router/                 маршруты и вкладки
    settings/               настройки устройства (язык, акцент)
    theme/                  цвета, шрифты, анимации, ThemeData
  features/<feature>/       одна папка на функцию: экраны, виджеты, логика
  shared/widgets/           переиспользуемые виджеты (оболочка, пустые состояния…)
  l10n/                     app_en.arb (шаблон), app_ru.arb; generated/ — не править
test/                       unit- и виджет-тесты; test/drift/ — тесты миграций
drift_schemas/              снапшоты схемы БД по версиям (коммитятся)
scripts/                    сборка, установка, обновление, бэкап
docs/                       документация
```

Когда функция разрастается, внутри `features/<feature>/` появляются подпапки
`data/` (репозитории, DAO), `domain/` (модели, логика) и `presentation/`
(экраны, виджеты, провайдеры). Маленькие функции остаются плоскими.

### Правила зависимостей

- `features/*` → могут использовать `core/` и `shared/`.
- `core/` → не импортирует `features/` (исключение: `core/router` собирает экраны).
- Фичи не импортируют друг друга напрямую; общее выносится в `core/` или `shared/`.

## База данных

Схема — `lib/core/database/tables.dart`. Два вида таблиц:

| Таблица | Вид | Назначение |
|---|---|---|
| `tracks` | синхр. | песня: теги, источник, лайк, **fingerprint** |
| `playlists` | синхр. | плейлист, флаг «офлайн» |
| `playlist_entries` | синхр. | трек в плейлисте, дробная позиция |
| `play_events` | синхр. | история прослушиваний |
| `library_folders` | локальная | выбранные на этом устройстве папки |
| `track_files` | локальная | файл на этом устройстве → трек |

**Синхронизируемые** строки: UUID-ключ, `updated_at` (last-write-wins),
`deleted` (надгробие, чтобы удаление тоже синхронизировалось).
**Локальные** таблицы описывают только это устройство и никуда не отправляются.
Подробнее — [SYNC.md](SYNC.md).

Пути к файлам отделены от треков намеренно: один и тот же трек на ПК и телефоне
лежит по разным путям, но в БД это одна запись `tracks`.

### Изменение схемы

1. Изменить `tables.dart`.
2. Поднять `schemaVersion` и добавить шаг миграции в `app_database.dart`.
3. `scripts/db-schema.sh` — сохранит снапшот схемы и прогонит тесты миграций.
4. Закоммитить `drift_schemas/` и `test/drift/`.

База лежит в support-каталоге приложения (Linux: `~/.local/share/com.viplayer.app/`,
Android: приватное хранилище) и переживает обновления.

## Тема и дизайн

- `AppColors` — чистый чёрный фон (OLED) и ступени почти-чёрных поверхностей.
- `NeonAccent` — акцент выбирается в настройках (циан, маджента, кислотный, фиолетовый).
- Фирменная форма — **скошенные углы** (`AppTheme.chamfer`) вместо скруглённых.
- Шрифты вшиты в приложение: Inter (интерфейс), JetBrains Mono (технические
  данные, заголовки секций `// РАЗДЕЛ`), Orbitron (только логотип — нет кириллицы).
- Анимации — `AppMotion.fast` (150 мс) / `normal` (250 мс), кривая `easeOutCubic`.
  Короткие и одинаковые по всему приложению.

## Локализация

- Языки: английский (по умолчанию) и русский; переключатель в настройках.
- Новые строки: добавить в `lib/l10n/app_en.arb` и `app_ru.arb`, затем
  `flutter gen-l10n` (или любой скрипт сборки).
- В коде: `AppLocalizations.of(context).someKey`. Строк прямо в виджетах нет.

## Соглашения по коду

- `flutter analyze` без замечаний — строгие правила в `analysis_options.yaml`.
- Форматирование — `dart format`.
- Комментарии и идентификаторы — на английском; документация — на русском.
- Новая логика сопровождается тестами (особенно БД, синхронизация, парсинг источников).

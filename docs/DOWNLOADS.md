# Скачивание

> Статус: **спроектировано**, реализация — этапы 5 (по ссылке) и 6 (по названию).

## Два режима

| Режим | Что делает |
|---|---|
| **По ссылке** | вставить ссылку на трек / альбом / плейлист → скачать |
| **По названию** | поиск → список результатов (обложка, длительность, источник) → скачать выбранное |

## Источники

Каждый источник — отдельный модуль с общим интерфейсом (`DownloadSource`):
поломка одного не затрагивает остальные, новые добавляются без переделки.

| Источник | ПК | Android |
|---|---|---|
| YouTube / YT Music | yt-dlp | Dart (youtube_explode_dart) |
| SoundCloud | yt-dlp | Dart (публичный API SoundCloud) |
| Spotify | метаданные из Spotify → звук с YT Music | то же |
| Прочие сайты (Bandcamp и т.д.) | yt-dlp | через ПК (удалённое скачивание) |

### Spotify

Звук Spotify защищён DRM — его не скачивает ни один инструмент. ViPlayer берёт
из ссылки Spotify метаданные (название, исполнитель, альбом, обложка,
длительность, ISRC), находит этот трек на YouTube Music и скачивает оттуда,
записывая теги и обложку Spotify. Пока поддерживаются **только ссылки**; поиск
по Spotify потребует бесплатного ключа разработчика Spotify.

### Устойчивость

Неофициальные API YouTube/SoundCloud периодически меняются.

- ПК: приложение умеет обновлять yt-dlp (`yt-dlp -U`).
- Android: ремонт — выпуском обновления приложения.

## Форматы

| Настройка | Результат | Когда выбирать |
|---|---|---|
| **AAC `.m4a`** *(по умолчанию)* | без перекодирования, теги и обложки | совместимость почти везде |
| Максимальное качество — Opus `.opus` | без перекодирования, лучшее доступное качество | слушать в ViPlayer / современных плеерах |
| MP3 *(только ПК)* | перекодирование через ffmpeg | только для старых устройств и магнитол — качество ниже, файлы больше |

После скачивания: запись тегов и обложки → файл в `Music/ViPlayer` → трек
появляется в медиатеке.

# Скачивание

> Статус: **готово** — по ссылке (этап 5) и по названию с прослушиванием (этап 6).

## Два режима

| Режим | Что делает |
|---|---|
| **По ссылке** | вставить ссылку на трек / альбом / плейлист → превью → скачать (у коллекций можно снять галочки) |
| **По названию** | поиск → результаты по источникам → **прослушать** любой → отметить галочками → «Скачать выбранные» |

## Что где работает

| Источник | ПК (Linux) | Телефон (Android) |
|---|---|---|
| YouTube / YT Music | ✅ yt-dlp | ❌ — см. ниже |
| SoundCloud | ✅ yt-dlp | ✅ Dart (MP3) |
| Spotify | ✅ метаданные Spotify → звук с YouTube | ❌ (звук с YouTube) |

### Почему YouTube не качается на телефоне

YouTube отдаёт полный поток только после решения JavaScript-задачи из своего
плеера (без неё — первый мегабайт, дальше `403`). yt-dlp на ПК решает её через
JS-движок (`deno`); в чистом Dart выполнить этот JavaScript нечем. Встраивание
JS-движка в APK отложено (решение пользователя, 2026-10-03): на телефоне YouTube
и Spotify скачиваются сторонними способами, а файлы из папок «Музыка»
подхватываются медиатекой автоматически (MediaStore). В планах синка (этап 7) —
удалённое скачивание: телефон отдаёт задачу ПК.

## Как устроено

`lib/core/download/`:

| Файл | Роль |
|---|---|
| `link_parser.dart` | распознаёт ссылки (короткие, мобильные, `music.youtube.com`, `spotify:` URI, локаль `intl-xx`) |
| `sources/youtube_source.dart` | метаданные и поиск YouTube на Dart (`youtube_explode_dart`) |
| `sources/soundcloud_source.dart` | API SoundCloud на Dart: публичный `client_id` со страницы сайта (обновляется сам), треки, плейлисты, MP3-поток |
| `sources/spotify_source.dart` | метаданные со встраиваемых страниц Spotify (без аккаунта и ключа) |
| `track_matcher.dart` | для Spotify подбирает ту же запись на YouTube: длительность, слова названия и исполнителя, штраф за live/cover/sped up и т.п. |
| `metadata_cleanup.dart` | «Artist - Title [NCS Release] (Official Video)» → исполнитель + название |
| `tools/ytdlp.dart` | yt-dlp: скачивание с прогрессом и отменой, установка/обновление своей копии |
| `tools/tagger.dart` | теги и обложка: ffmpeg на ПК (все форматы; в Opus — `METADATA_BLOCK_PICTURE`), Dart на телефоне |
| `download_service.dart` | путь одного трека: совпадение → звук → обложка → теги → файл → медиатека |
| `download_queue.dart` | очередь: по 2 загрузки, отмена, повтор |

Путь трека:

1. **Spotify** → поиск на YouTube (`TrackMatcher`); не нашлось — «не найдено на YouTube».
2. Звук: yt-dlp (ПК) или Dart (SoundCloud на телефоне).
3. Обложка: Spotify / SoundCloud — квадратная; YouTube — превью 16:9, обрезается до квадрата.
4. Теги: название, исполнитель, альбом, год, номер трека, обложка.
5. Файл: `Music/ViPlayer/<Исполнитель> - <Название>.<ext>`.
6. Импорт в медиатеку сразу (без полного сканирования) + запоминается источник —
   повторное скачивание той же ссылки распознаётся как «уже в медиатеке».

### Поиск и прослушивание

- Ищет в источниках, из которых устройство может скачать: ПК — YouTube и
  SoundCloud, телефон — SoundCloud. YouTube без шортсов и многочасовых миксов;
  SoundCloud без «сниппетов» Go+ (30-секундные превью, целиком не скачать).
- Прослушивание идёт в **отдельном проигрывателе** (`core/player/preview_player.dart`):
  очередь не трогается, основной плеер ставится на паузу; запуск основного
  плеера останавливает превью.
- SoundCloud — прямой поток. **YouTube** отдаёт прямые ссылки нестабильно
  (случайные `403` после первого мегабайта), поэтому на ПК превью скачивается
  yt-dlp в кэш (~2 с) и играет из файла; «Скачать» после прослушивания берёт этот
  файл (M4A) без повторной загрузки. Кэш очищается при каждом запуске.

### yt-dlp

ViPlayer использует свою копию `~/.local/share/com.viplayer.app/bin/yt-dlp`, если
она есть, иначе системный `yt-dlp`. Кнопка **Настройки → Загрузки → Обновить**
скачивает свежий релиз в папку приложения (системный пакет изнутри приложения не
обновить, а сервисы ломают старые версии быстро). Для YouTube yt-dlp нужен
JS-движок — на Arch `deno` ставится как зависимость пакета `yt-dlp`.

### Ограничения

- Плейлисты Spotify: встраиваемая страница отдаёт ограниченное число треков
  (решает Spotify). Альбомы — полностью.
- Неофициальные API меняются. ПК: обновить yt-dlp. Телефон (SoundCloud): обновить
  ViPlayer. Онлайн-тесты источников: `flutter test --tags online --run-skipped`.

## Форматы

| Настройка | Результат | Где |
|---|---|---|
| **AAC `.m4a`** *(по умолчанию)* | без перекодирования | ПК |
| Opus `.opus` | без перекодирования, лучшее качество YouTube | ПК |
| MP3 | перекодирование ffmpeg (VBR, максимальное качество) | ПК |
| MP3 (как отдаёт SoundCloud) | без перекодирования | телефон |
